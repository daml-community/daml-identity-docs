# For Organisations
The following provides documentation for organisations wishing to add or modify their keys on the repository.

## Who are "organisations"?
As [outlined](https://github.com/canton-foundation/canton-dev-fund/blob/a51bd2127e5b4157afa1d364b0217f2063bb344d/proposals/2026-07-Obsidian-Package-Distribution.md#keys-of-publishers-and-auditors) in the project proposal, the repository provides a mechanism for recognised DAML **auditors** and **publishers** to register their identities. These two types of users will be referred to more generally as **organisations**.
