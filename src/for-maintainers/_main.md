# For Maintainers
The following provides documentation for actions carried out by maintainers.

## Who are "maintainers"?
The initial proposal [references](https://github.com/canton-foundation/canton-dev-fund/blob/a51bd2127e5b4157afa1d364b0217f2063bb344d/proposals/2026-07-Obsidian-Package-Distribution.md#keys-of-publishers-and-auditors) a:

> "Consortium of trusted parties who decide which key submissions are valid"

These will be referred to as **maintainers**.
The current maintainers are:
- **Digital Asset**
- **Canton Foundation**
- **Obsidian Systems**
